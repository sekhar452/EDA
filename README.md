# Exploratory Data Analysis (EDA) with Python

## 📌 Project Overview

This repository focuses on Exploratory Data Analysis (EDA) and data preprocessing techniques using Python. It demonstrates how to inspect datasets, understand data distributions, identify patterns, handle data quality issues, and prepare data for machine learning workflows.

The repository includes practical exercises using datasets such as Red Wine Quality and Student Performance, along with essential data preprocessing techniques.

## 🎯 Objectives

- Understand dataset structure, data types, and statistical summaries.
- Explore data distributions and relationships between variables.
- Visualize patterns and trends using charts and graphs.
- Identify and handle missing values and outliers.
- Apply feature scaling and categorical encoding techniques.
- Understand class imbalance and apply SMOTE where appropriate.
- Prepare clean, structured data for machine learning models.

## 🛠️ Technologies & Libraries

- **Python** — Data analysis and preprocessing
- **Pandas** — Data manipulation and analysis
- **NumPy** — Numerical computing
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualization
- **Scikit-learn** — Data preprocessing utilities
- **Imbalanced-learn** — Handling imbalanced datasets with SMOTE
- **Jupyter Notebook** — Interactive analysis and experimentation

## ⚙️ Installation & Setup

**Step 1: Clone the repository**

```bash
git clone <your-repository-url>
cd Exploratory-Data-Analysis
```

**Step 2: Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn jupyter
```

**Step 3: Launch Jupyter Notebook**

```bash
jupyter notebook
```

Open any notebook to review the code, analysis, visualizations, and outputs.
